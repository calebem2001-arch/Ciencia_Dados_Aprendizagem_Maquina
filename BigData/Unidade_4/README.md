
# Unidade IV e análise do Pescadores Web

Esta pasta preserva a definição revisada do projeto de TCC.

A parte prática de Ciência de Dados está em
[Projeto_ciencia_de_dados](../Projeto_ciencia_de_dados/README.md), com dados
